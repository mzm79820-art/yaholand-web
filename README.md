# 야호랜드 웹 MVP

카카오톡 봇(조아 봇) 규칙을 바탕으로 만든 **텍스트 기반 RPG** 모바일 웹입니다.

## 포함된 기능 (MVP)

- 회원가입 / 로그인 (아이디·비밀번호·닉네임)
- 가위바위보 (하루 20회)
- 주사위 (하루 20회)
- 낚시 (미끼 상점, 낚싯대 성장, 도감)
- 펫 (입양, 산책, 훈련, 간식)
- 직업 (5종 전직, 슬라임 훈련)
- 던전 (탑 공격, 장비 장착/판매)

## 실행 방법

1. Node.js 18 이상 설치
2. 터미널에서 이 폴더로 이동

```bash
cd yaholand-web
npm install
npm start
```

3. 브라우저에서 http://localhost:3000 접속

개발 중 자동 재시작:

```bash
npm run dev
```

## 폴더 구조

- `server/` — API, DB, 게임 규칙 (서버에서만 점수 계산)
- `public/` — 모바일 화면
- `data/` — 유저/세션/플레이 데이터 JSON (실행 후 생성)

## 참고

- 원본 봇 파일 `야호`는 **에디터에만 있고 디스크에 0바이트**일 수 있습니다. Cursor에서 `야호` 탭을 저장(Ctrl+S)해 두세요.
- 웹 초반 경제(미끼 가격, 던전 보상 등)는 신규 서버용으로 일부 낮춰 두었습니다.
